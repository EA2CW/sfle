# SFLE - Simple fast log entry

**Simple fast log entry** - a tool to enter QSOs from your SOTA/GMA/WWFF activations and create the ADIF files - everything just in your browser.

## Working application is available on **[sota.gautxori.eus/sfle](https://sota.gautxori.eus/sfle)**

Written by [Petr, OK2CQR](https://www.ok2cqr.com).
Modified by Mark M5TEA and Mikel EA2CW starting 2026-08-02.
 
Based on [FLE](https://df3cb.com/fle/) from [Bernd, DF3CB](https://df3cb.com/). Unfortunately, Fast Log Entry works only on Windows and Linux using Wine, but I needed something working on macOS and/or Android tablets and smartphones.
